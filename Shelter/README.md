# Underhaven (Shelter v1)

- `Shelterv1.rbxl`: the place file as uploaded.
- `Shelterv1-fixed.rbxl`: the same place with the bug fixes, emergency response and sound added. Only scripts changed or were added; the map, meshes and settings are untouched.
- `src/`: the game's scripts (ReplicatedStorage, ServerScriptService, StarterPlayer), extracted from the place. Edit these, then rebuild the place.
- `audio/underhaven_sounds.ogg`: optional backup sounds, generated in-house (see **Sound**).
- `tests/`: headless tests for the server code and the sound controller (fake Roblox APIs, virtual clock, DataStores with latency and failure injection).
- `tools/`: the place file reader/writer, the backup sound generator and its uploader.
- `DESIGN_STATUS.md`: where the game stands against the design brief, section by section.

> **If you use `_DevSync`:** it overwrites scripts from your local source folder. Copy `src/` into that folder first, or a sync will undo these changes.

## Sound

Sound works out of the box: every cue uses **public Roblox audio** from the Creator Store. Almost all of it comes from Roblox's licensed Pro Sound Effects library (titles ending in "(SFX)"), which any experience may play, so nothing has to be uploaded.

- `src/ReplicatedStorage/Shared/SoundBank.lua` lists each game event's audio IDs, with their store titles in comments, plus volume, pitch and how many seconds to play. To change a sound, put a different Creator Store audio ID first in that cue's list.
- Each cue has backups. On join, the client checks each ID actually loads (`ContentProvider:PreloadAsync`) and uses the first one that does, because Roblox sometimes makes audio unavailable. In Studio, the Output names any cue left with no playable audio.
- Long library clips are cut to the right length with a short fade. Each weapon has its own gunshot. The ambient loops follow the camera: machinery hums and fires crackle when on screen, water slows in a brownout, and an air-raid siren sounds during raids.
- A **SOUND** button in the bottom-right corner toggles effects and ambience; the choice is saved per player.

Optional: `audio/underhaven_sounds.ogg` holds 34 original sounds generated by `tools/make_sounds.py`. They're used only as a last resort, if you upload that file and set `SoundBank.ATLAS_ID` (`tools/upload_sounds.py` can do it with an Open Cloud key).

## Run the tests

Needs the [Luau CLI](https://github.com/luau-lang/luau/releases) (`luau`) and Python 3.

```sh
LUAU=/path/to/luau python3 tests/run.py          # all tests
LUAU=/path/to/luau python3 tests/run.py smoke    # one test; -v shows output
```

Each test runs in a fresh process. `smoke` plays 25 virtual minutes with every system involved. `scale_*` measures server cost at 200 and 500 survivors. The rest each cover one bug or feature.

## Rebuild the place after editing `src/`

```sh
pip install lz4 zstandard
python3 tools/build_place.py Shelterv1.rbxl Shelterv1-fixed.rbxl
```

The script replaces the `Source` of every script that has a file under `src/`. A new `.lua` file becomes a new ModuleScript in its folder. All other data is copied byte for byte, and the result is re-read and checked.
